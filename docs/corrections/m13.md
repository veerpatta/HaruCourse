## 2. Fact and arithmetic checks

- Misconception "renaming one token is a one-character change" → one-word edit (surface-alt → surface-muted is not one character); check-Q&A likewise.
- "A changed default is a breaking change" was presented as a universal rule. It is now a written policy of the learner's system (explanation, check 2 stem, sorter feedback), noting some systems class visual-only changes as minor.
- SemVer: major/minor/patch definitions, "released version never modified", "at least one minor release with the deprecation before removal" checked against the specification's text as already cited in the resource notes. Transfer l08: 2.3.1 → 2.4.0 (new token name + compact size + focus fix, old name deprecated) → 3.0.0 (removal).
- Starter contrast (WCAG formula, script-checked): label #1f2a28/#fbfaf6 14.16; hint #55615e 6.17; white on action #1d5c4d 7.81, on hover #174a3e 10.07, on active #12332b 13.69; error #a3271b 7.02 (6.32 on tint); success #2e7d5b 4.79 on plain but **4.31 on tint #e8f0ec** (planted, fails 4.5); focus #b8500f 4.80 (4.32 on tint, passes 3:1); field border #6b7a76 4.31 (3:1); disabled text #4a5653 on #d9dedc 5.62. Transfer l02: #8a8a8a on white 3.45.
- Planted drift: token table says space-3 = 12px; stylesheet declares 16px — confirmed in the browser (computed padding-left 16px).
- Every lesson example now labelled "Example (made up)"; l09 example no longer cites "m05 research".
