## 2. Facts checked (2026-10-04)

- Microsoft Support, Complete guide to Narrator: built into Windows 10/11; start/stop Windows logo key + Ctrl + Enter; Narrator key Caps Lock or Insert; Ctrl stops reading; Narrator + Esc exits; scan mode Narrator + Spacebar, on automatically in Edge/Chrome/Firefox; H, K, F, D.
- NV Access NVDA User Guide: Control + Alt + N (if shortcut created); NVDA + Q then Enter; Control stops speech; NVDA key Insert.
- Apple VoiceOver User Guide (Mac): Command-F5 or Command + Touch ID ×3; VO = Control-Option or Caps Lock; Control pauses; Fn may be needed with function keys. Apple iPhone User Guide: Settings > Accessibility > VoiceOver, Accessibility Shortcut (triple-click side/Home button), Siri; two-finger tap pauses; VoiceOver changes gestures. Safari: Settings > Advanced > “Press Tab to highlight each item on a webpage”.
- Google Android Accessibility Help: hold both volume keys a few seconds once the shortcut is set; “Hey Google, turn off TalkBack”; two-finger tap pause/resume (TalkBack 9.1+).
- W3C Understanding 1.4.3: 4.5:1, large text 3:1; inactive UI components, pure decoration and logotypes have no requirement. 1.2.2 (A): captions for prerecorded audio in synchronized media. 1.2.1 (A): audio-only/video-only alternatives. 1.2.3 (A): audio description or media alternative for the visual content.
- GOV.UK participants page (last updated 22 September 2026): allow up to a month for disabled participants; contact organisations at least a month ahead; 6–8 weeks for less common cognitive disabilities. l12 explanation, remediation, check feedback and resource limits corrected (they said “last updated 28 April 2020”).
- Colour-vision prevalence hedged to “roughly one man in twelve in many populations”.

## 5. Remaining limits

- The lab page was checked in an emulated browser only (320 px, structure, ids). It has not been used with a real screen reader or on a phone; controls are as documented by the vendors on 2026-10-04 and change between versions.
- No working practice form is supplied, so forms and announcement checks run on the learner’s own page, a public page (nothing typed or submitted), or on paper as specified-and-untested.
- A learner’s own session does not establish what disabled people experience; every lesson keeps that boundary.
