## 2. Arithmetic and fact checks

- Length rule (brief): defensible ≤ 1.15 × longest alternative and 0.7–1.3 × mean of alternatives. Example, L2 check 1: defensible 98; alternatives 93 and 101 → 98 ≤ 1.15 × 101 = 116.2; mean 97, ratio 1.01. All 24 M1 questions verified by `check-questions.mjs` (zero issues for lessons 2–7).
- Option counts: 3+3+3+4 per lesson as before; `was` count = 80 options (L2 13, L3 15, L4 12, L5 13, L6 14, L7 13).
- Reading/focus order facts: Tab moves only between focusable controls; static text receives no focus; a hint is announced on focus only when programmatically associated (for example `aria-describedby`) — some screen readers may read nearby text, so the copy says “usually”. Reading order in browse mode follows DOM order.
- Creator access: `server/data.ts` line 21 resolves the creator to Haru’s records, so saved answers are readable without Ready for review.
