# Pilot observation sheet

One sheet per participant, filled in by the observer during the sessions in [the pilot test script](PILOT-TEST-SCRIPT.md). Record what the participant does and says, not what they should have done. Keep this sheet off the course server; delete it on the date agreed in consent. Use the participant code (pilot-N), never a name.
