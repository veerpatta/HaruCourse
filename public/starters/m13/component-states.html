Content rules, boundaries and open decisions

  • Button labels start with a verb and stay under about 24 characters. Long labels wrap; they are never cut short.
  • Every field keeps a visible label. A hint explains any format. An error message says how to fix the problem, not only that there is one.
  • Not for navigation: use a link to go to another page. Not for choosing from a short fixed list: use radio buttons or a select.
  • Every state can be told apart without colour: words, icons, border style or border thickness change too.
  • Open decision: whether a disabled button should stay focusable, so that someone using a keyboard can find out why it is unavailable.
